# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Employees (new hires in Indian tech hubs), HR Admins, IT Provisioning, Managers, and Compliance Officers.

## Product Purpose
An Employee Onboarding Management System (EOMS) to manage and track the full onboarding lifecycle: 30/60/90-day ramp-ups, statutory compliance (POSH, Data Protection), document verification (PAN, Aadhaar), and IT asset allocation.

## Positioning
A minimalist, high-clarity orchestration platform that replaces enterprise bloat with focused, chart-led progressive disclosure and smooth interactions for Indian corporate environments.

## Operating Context
Used daily during the first 90 days by new hires. Used continuously by HR and IT to manage cohorts across multiple hybrid tech hubs (Bengaluru, Hyderabad, Pune, Gurugram, etc.). Heavy reliance on dashboards, document review, and task tracking.

## Capabilities and Constraints
- Role-Based Access Control (RBAC) with specific dashboards for HR, IT, Manager, and Employee.
- Includes charts and visualizations (Recharts integrated) for metrics.
- Smooth animations via framer-motion (and optionally GSAP, Lenis, etc.).
- React 18 frontend, Vite build tool. Express/Sequelize backend.

## Brand Commitments
"Employee Onboarding Management System" (EOMS). Needs a highly minimalist, visually stunning, content-light, low cognitive load design. Focus on clarity and progressive disclosure. References: modern smooth animated dashboards, like the provided HR_Dashboard.webp.

## Evidence on Hand
Implementation already features full backend (REST API, Sequelize models) and a complete React frontend with Framer Motion, Recharts, and minimalist UI components. Reference images are provided for the desired aesthetic.

## Product Principles
1. **Progressive Disclosure**: Show only what's necessary; hide secondary filters and lists until requested.
2. **Visual First**: Use charts, graphics, and smooth animations (MiniDonuts, Sparklines, etc.) to communicate status instantly instead of walls of text.
3. **Low Cognitive Load**: Maintain a calm, neutral, and minimalist aesthetic with ample whitespace and clear typography.
