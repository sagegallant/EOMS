Quick Hover Explainer:
MFA
MFA
Multi-Factor Authentication
Requires two or more identity credentials before issuing access tokens.
In EOMS: Primary password verified first; requires 6-digit TOTP before session JWT tokens are granted.
TOTP
TOTP (RFC 6238)
Time-Based One-Time Password
A shared secret and current 30-second Unix time slice generate an ephemeral 6-digit code.
In EOMS: Handled via `otplib`. Calculates current step with ±1 step window tolerance for clock drift.
JWT
JWT (HS256)
JSON Web Token
Digitally signed, stateless token containing claims like userId, role, and department.
In EOMS: 15-minute access token in Authorization header; 7-day rotating refresh token in MySQL.
RBAC
RBAC
Role-Based Access Control
Restricts system access based on user roles and mapped capabilities.
In EOMS: Users -> Roles -> RolePermissions -> Permissions. Middleware checks required capability.
TTL Cache
TTL (60s)
Time-To-Live In-Memory Cache
Expiration duration for cached data in server memory.
In EOMS: Resolves role permissions in sub-millisecond RAM. Automatically evicts after 60s to refresh permissions.
ACID Tx
ACID Transaction
Atomicity, Consistency, Isolation, Durability
Guarantees that database multi-table modifications succeed completely or roll back entirely.
In EOMS: User, Employee, Tasks, and Asset requests created in one atomic transaction; rolls back on failure.
SELECT FOR UPDATE
SELECT ... FOR UPDATE
Pessimistic Row-Level Locking
Locks retrieved database rows until the transaction finishes, blocking concurrent writers.
In EOMS: Prevents double-allocation of laptops by locking the hardware row during IT assignment.
SHA-256
SHA-256
Secure Hash Algorithm 256-bit
Cryptographic fingerprint guaranteeing tamper-proof file and password security.
In EOMS: Hashes uploaded documents upon arrival to prove zero tampering during compliance audits.
SLA Sweeper
SLA Engine
Service Level Agreement Scheduler
Automated monitoring system verifying that onboarding milestones meet their due dates.
In EOMS: Node-Cron sweeps active tasks; flags overdue items and dispatches manager escalation notifications.
